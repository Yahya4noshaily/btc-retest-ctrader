# BTC Retest · cTrader
لوحة عربية مستقلة ترصد BTCUSD من حساب الوسيط عبر cTrader Open API. تعمل المراقبة والتنبيهات أثناء فتح الصفحة ونشاطها. الأسعار من حساب cTrader المختار، والتنبيهات للمتابعة اليدوية.

## الربط
انشر المشروع على Vercel باستخدام مجلد الإخراج public. أضف رابط /callback.html الكامل المعروض داخل الموقع إلى Redirect URIs في تطبيق cTrader المعتمد. أدخل Client ID وClient Secret داخل الموقع ثم فوّض حسابك بصلاحية accounts. يمكن أيضًا إدخال Access Token ساري للتطبيق نفسه. اختر البيئة والحساب ثم ابدأ المراقبة. يحفظ الموقع بيانات الربط مؤقتًا في جلسة التبويب للعودة من التفويض خلال عشر دقائق ويحذفها من مخزن الجلسة عند تحميل اللوحة. يبقى رمز الوصول في ذاكرة الصفحة، وتستخدم دالة /api/exchange مفتاح التطبيق لمبادلة كود التفويض فقط. عند انتهاء الرمز أعد التفويض.

## القواعد
يعتمد الاتجاه على آخر قمتين وقاعين مؤكدين على M5. تتطلب القمة أو القاع شمعتين مكتملتين على كل جانب. يفعّل إغلاق M1 خلف آخر قمة أو قاع مرحلة إعادة الاختبار حتى خمس شمعات. يجب أن تلمس شمعة لاحقة المستوى وتغلق جهة الاختراق. نحسب الوقف بمقدار أصغر وحدة سعر خارج شمعة الاختبار. تعرض الواجهة سعر Ask للشراء وBid للبيع. نافذة إصدار التنبيه 12 ثانية من الإغلاق مع سعر حديث. السجل خاص بالجلسة. الإعدادات أولية ولم يتم قياس ربحيتها.

## التحقق
شغّل npm test باستخدام Node.js 22 أو أحدث. لا يحتاج المشروع إلى تثبيت حزم.
